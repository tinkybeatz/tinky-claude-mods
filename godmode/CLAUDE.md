# godmode — project context

This folder holds the brainstorm for a Claude Code mod that turns on a full agentic
development loop (a PM session that plans and dispatches dev and review agents) in any
project. Nothing is being built yet: the phase is
brainstorming.

**Before answering anything here, read `brainstorm-log.md`.** It is the source of truth
for what has been discussed, what was decided, and why. The conversation is not.

Rules for the log:

- Append-only. New entries go at the bottom; never rewrite, reorder, or tidy past ones.
- Every decision is recorded with the reason behind it. The why is the point.
- Messy is acceptable. Lossy is not.
- Open questions stay listed until they are answered, then move into the decisions.
- Unagreed ideas are logged as "proposal, not decided". A decision number (Dn) is given
  only after Gael explicitly says yes to that specific point.

How to run the brainstorm:

- One topic and one question per reply. Never a list of questions, not even as a recap.
- Define any term before using it, with an example.

Do not start building unless Gael explicitly asks. When building starts, load the
`plugin-authoring` skill first, and follow the repo's root `CLAUDE.md`.
